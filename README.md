# Classic Minecraft Beta 1.7.3 Portable Client (Java 8 Fix)

Полностью настроенный, чистый и портативный клиент **Minecraft Beta 1.7.3** со всеми оригинальными библиотеками LWJGL и исправленным сетевым кодом для стабильного запуска на **Java 8** напрямую без лаунчеров.

##  Фишки сборки
* **Запуск в один клик**: Запускается через универсальный `.bat` файл, минуя любые тяжелые лаунчеры.
* **Исправление вылетов**: Полностью решена проблема с сетевой ошибкой `NullPointerException` при спавне на серверах.
* **Автономность**: Все оригинальные библиотеки (`lwjgl`, `jinput`) и папка `natives` со старыми `.dll` уже собраны на своих местах в папке `bin`.
* **Портативность**: Клиент не привязывается к путям на компьютере — всю папку со сборкой можно переносить на флешку или другие диски.

---

## Структура проекта
* `play.bat` — универсальный скрипт для запуска игры (автоматически передает ник и фантомный сессионный токен для авторизации).
* `bin/` — папка со всеми `.jar` файлами игры и оригинальными нативами.

---

## Инструкция по запуску и настройке

1. Убедитесь, что папка `java8` находится в корневой директории клиента (рядом с `play.bat` и папкой `bin`).
2. ВНИМАНИЕ,папку нужно скачать отдельно ссылка:https://drive.google.com/file/d/1udN258QI8K2rmrVd-q_Fl-X8JO8jPJJl/view?usp=sharing
3. Нажмите правой кнопкой мыши по файлу **`play.bat`** -> **Изменить** (через Блокнот).
4. В самом конце строки вместо слова `danger` впишите свой игровой ник английскими буквами. Сохраните и закройте файл.
5. Дважды кликните по **`play.bat`** для запуска игры.
6. Для игры по сети нажмите **Multiplayer** и введите адрес сервера (например, `localhost` для игры на своем ПК или адрес друга через `frp`/Radmin VPN).
